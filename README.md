This repository is my personal learning journal for **Cohort 2**. I created it to keep everything organized in one place while learning Full Stack Development.

Instead of keeping code scattered across multiple repositories, I maintain all my daily practice, assignments, notes, experiments, and mini-projects here. It helps me stay consistent, track my progress, and revisit concepts whenever needed.
